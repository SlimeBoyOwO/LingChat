# 暮色节拍：主程序小游戏

入口：**开始游戏 → 小游戏 → 暮色节拍**。

原有「小游戏（开发中）」占位项现已启用。小游戏选择沿用主程序的蓝天背景、角色、Logo 和大字菜单，不再使用独立的卡片列表页。返回选择菜单的路由为 `/mini-games`，音游为 `/mini-games/twilight`，均为懒加载路由。菜单和入口提供简体中文、繁体中文、英语、日语文案；当前曲目内部的剧情和说明为中文。

## 内容

黄昏神社像素场景、钦灵四帧透明角色动作、四键单点与长按、约 72 秒的原创练习曲《灯下回声》（112 BPM、138 个音符）、音量/输入偏移/下落时间调校、暂停重试、观赏演示与可选异常演出。

标题旁的左右箭头切换曲目，记住上次选择。两首曲目的音乐、谱面、HUD 和结算信息独立切换：

| 曲目     | 难度   | 风格                        | BPM | 时长     | 音符 |
| -------- | ------ | --------------------------- | --- | -------- | ---- |
| 灯下回声 | 入门 3 | Chiptune                    | 112 | 约 72 秒 | 138  |
| 霓虹过载 | 专家 9 | 原创 Electro / Melodic Bass | 168 | 约 83 秒 | 608  |

《霓虹过载》包含 64 组双押和 14 个长按，分为起拍、上升段、第一段 Drop、间奏和最终 Drop。八分音符交替、十六分音符连打与长按穿插随编曲变化，避免长按未结束时在同一轨道安排新音符。鼓组、切分低音、失谐合成器与铃音均由代码生成，无外部采样。

新曲使用紫蓝霓虹配色、节拍光束、透视地面网格、灯带、打击扩散和每 50 连击的提示。特效绘制与音符判定分开，粒子和扩散数量有上限；「调校 → 节拍特效」可关闭动态效果，也跟随系统减少动态效果设置。

场景铺满主窗口内容区，没有网页顶栏、宣传文案、外框、底部信息栏或页面滚动。前景画布等比缩放，背景覆盖整个窗口；触摸区域随画布缩放并对齐轨道。开始、调校、暂停和结算均在场景内显示，菜单字体沿用主程序。进入小游戏不会强制改变操作系统窗口模式。

按 `D / F / J / K` 演奏，按 `Esc` 暂停；暂停菜单可继续、重试、调校、返回曲目或返回小游戏。调校界面按 `Esc` 关闭后保持暂停，避免误恢复。开始界面的「返回」也能直接回到主程序小游戏菜单。

手机与平板可以直接点按下方四键，支持多指和弦与长按。竖屏时谱面横向铺开，角色与成绩移至上方；触摸横屏加宽轨道并保留至少 48 像素的按键目标。画布保持等比，按钮避开系统安全区。旋转屏幕、失焦或音频被系统中断时暂停，点击继续后准备三拍。短屏的暂停菜单分两列，调校与结算可在弹层内部滚动；详见 [移动端适配](minigames-mobile.md)。

背景和角色通过内置 image_gen 生成，角色参考项目原有钦灵形象。角色图已清理棋盘格背景并统一脚底基线。项目只打包实际使用的背景和四张角色帧；它们位于 `src/assets/minigames/twilight/`，经 Vite 解析和打包，不依赖本机绝对路径、原型目录或本地 HTTP 服务。

音乐由 `music.js` 中的原创程序合成定义生成，不依赖远程歌曲、外部采样或运行时音频文件路径。

`songs.js` 管理曲目，`music.js` 与 `neon.js` 分别生成两首音乐和谱面。`music-worker.js` 在独立 Worker 中合成 PCM，再交给主线程播放，避免准备新曲时阻塞手机界面。只缓存当前曲目的音频缓冲；切歌替换缓冲，合成途中退出会终止 Worker。演示按时间顺序处理按下/释放事件，支持密集谱面、卡帧追赶与暂停后的长按续接。结果包含曲目 ID、曲名和音符总数。

手机虚拟按键只在 Android、iPhone 和 iPad 上显示；Windows/macOS 使用键盘，即使 Windows 带触摸屏或桌面窗口缩窄，也不显示手机按钮。

## 运行与资源归属

`TwilightRhythm.vue` 在主窗口内挂载画布和 Web Audio。静态模板和样式使用 Shadow DOM 隔离，避免像素游戏样式污染主菜单，或剧本的全局红色 UI 覆盖游戏；没有 iframe、外部网页或附加窗口。

主窗口现有 AudioContext 包装仍可为小游戏选择输出设备。该页面不进入聊天路由，主动对话不会在此投放。

每次挂载都有独立 AbortController。返回列表、路由切换、初始化途中退出及页面关闭都会停止音源、关闭 AudioContext、清除按键和触摸状态、移除事件监听并取消动画帧。再次进入创建新的会话，不复用上次时钟或得分。

小游戏暂停音乐与谱面，继续前准备三拍；未完成的长按可在恢复点重新接住。观赏演示显式标记 DEMO，不冒充玩家成绩。异常模式尾声返回 `interrupted`，可以重试或返回。

## 检查

- `node scripts/test-twilight-core.mjs`：判定窗口、长按、重复输入、暂停续接、整谱全命中及全漏击。
- `scripts/mini-games-smoke.html`：仅开发检查使用，挂载真实 Vue 菜单、列表和音游组件。
- `scripts/test-mini-games-browser.cjs`：检查主菜单与小游戏共用背景、页面跳转、不同窗口比例下铺满且无滚动、场景内调校、素材、按键、暂停、音频及监听清理、反复进入、加载途中退出、窄屏和返回主菜单。需要 Playwright，可通过 `CHROME_PATH` 指定已有浏览器，通过 `TEST_URL` 指定 Vite 检查页。
- 发布验证使用完整 `pnpm tauri build --no-bundle`。
- `node scripts/test-twilight-neon.mjs`：608 音符全连/全漏、长按间隔、双押、音频 PCM 与桌面/移动端识别；可用 `TEST_OUTPUT` 输出完整 WAV 与检测报告。
- `scripts/test-twilight-songs.cjs`：选曲与正确音频缓冲、Worker 清理、完整高密度演示、间奏暂停续接、特效开关、减少动态效果、手机选曲及桌面隐藏手机按键。

此版本接入的是主程序小游戏入口。供 DLC 剧情调用的 `rhythm_game` 事件及结果变量写回属于后续扩展，没有把未实现的剧本事件暴露给作者。
