# P5：聊天自动回忆与记忆搜索工具

日期：2026-10-18。

复审补充：P0–P5 全面检查发现的笔记写工具、角色切换队列与自动保存衔接问题已修复，见 [复审与修复记录](memory-rag-p05-review.md) 第 6 节。最新回归共 216 项通过；模型请求来源已沿真实 producer 队列传递，并覆盖积压旧句的时序。

## 1. 本阶段行为

有用户输入时，在既有近期原文、四段摘要和世界书基础上，用本轮输入检索当前角色在当前存档中感知过的历史与自己的笔记，再调用聊天模型。通知、主动发言等没有用户输入的路径默认不自动检索；角色仍可在获得工具权限后主动搜索。超过 4096 字符的输入跳过自动检索，普通聊天继续。

自动回忆和 `memory_search` 使用同一个宿主服务、同一个共享向量引擎、同一份查询向量／检索结果 LRU。首次请求先增量同步派生索引；后续复用已持久化的向量。排序与阈值沿用 P3–P4，本阶段没有根据保留集调参。

一轮自动回忆与工具搜索合计最多引用 5 条、1800 个 Unicode 字符，包含来源头开销。重复正文只交付一次；达到预算后可以返回空结果。参考资料插入请求副本，最后一条用户问题保留在末尾，正文明确标记为历史数据，并提示区分计划、假设与已发生事实。

原始聊天台词不写入检索参考块。工具调用与返回仍保持配对，但 `memory_search` 的持久化结果换成临时资料标记，后续回合需要重新检索；工具参数、角色实际生成的回答仍按原来的聊天流程存储。调试和工具活动事件可展示当前结果，不等于把原始检索正文写入台词表。

## 2. 使用入口

- 高级设置 → 记忆系统：历史记忆检索默认开启；超时默认 2000ms，范围 100–10000ms，保存后下一次检索生效。摘要压缩开关独立控制。
- 工具设置 → 笔记与记忆：按既有权限矩阵允许 `memory_search`；开启 Tool RAG 后由 `tool_search` 发现和激活。自动回忆使用记忆系统开关，工具开关控制模型能否主动调用搜索。
- 高级设置 → 记忆调试：展开“本轮历史记忆检索（RAG）”，刷新查看最近一次搜索的状态、查询、来源、排名说明与缓存标志。这里展示搜索快照，重复预算过滤后的实际交付条数可能更少。切换角色、存档或修改历史后不展示旧快照。

工具参数示例：

```json
{ "query": "上次收到的礼物是什么？", "max_hits": 3, "kinds": ["raw", "note"] }
```

`query` 必填；`max_hits` 为 1–5；`kinds` 可选 `raw`、`diary`、`note`，省略表示全部。角色、存档由宿主确定，不能由参数选择。全局关闭时工具返回 `disabled`，不会继续执行内容检索。

## 3. 会话与来源保护

检索前捕获角色、存档、生成代号与运行时历史指纹；请求聊天模型前、工具轮次前后、回复落入历史前、最终有序发送前再次检查。普通追加台词不取消当前请求；角色／存档切换、读档、撤回、原文或感知范围变更会取消旧请求。每次模型请求的固定快照通过控制帧送入 producer，并随句子和栅栏入队；其中的上下文版本还用于拒绝同角色笔记变更前生成的旧回复。合法上下文重建后逐项丢弃旧来源，继续发送新回复。

引用过资料时，发送前重读来源范围。笔记变化会取消该轮旧资料；持久历史变化只有在原历史完整保留为前缀、引用源版本和完整工具事务仍有效时，才允许继续。这支持本轮生成过程中追加存档，同时拦截源内容改写。检索开始时还要求数据库历史是运行时历史的前缀，防止未保存的编辑或撤回继续使用旧数据库事实。

本轮笔记写工具执行前主动作废旧引用，从未注入 RAG 的请求副本重建后续上下文，保留成功／失败结果与工具配对；同批剩余调用返回未执行。旧检索结果和基于其生成的临时前导正文不再进入续写，累计引用预算不重置。外部编辑仍按来源变化取消旧资料。

定时／退出自动保存等待完整生成结束再执行，剧本 AI 生成也参与同一生成锁，避免仅因自动槽编号变化而误取消回复。等待时不持有自动保存管理器锁；退出保存仍保留原有 5 秒总超时。

`character_switch` 成功后重新捕获目标角色上下文，清除上一角色的临时资料与预算，再计算目标角色工具权限。同批剩余工具调用返回“未执行”，交由新角色重新发起，避免使用旧角色权限和资料继续执行。

新增工具的权限回归发现并修复既有空列表放行问题：只有显式 `all_tools=true` 才代表全部允许；单边全部允许与另一边空列表求交时得到空集。

## 4. 降级与边界

| 状态             | 含义                                                     |
| ---------------- | -------------------------------------------------------- |
| `ready`          | 搜索完成，命中可以为空；向量是否可用另看 `vector_status` |
| `disabled`       | 全局开关关闭，或编辑器试玩禁用自动回忆                   |
| `empty_query`    | 空查询，无需检索                                         |
| `no_active_save` | 当前没有绑定存档，跳过检索                               |
| `busy`           | 前一次索引／搜索仍在执行，本次跳过                       |
| `timeout`        | 等待超过配置期限，普通聊天继续                           |
| `unavailable`    | 索引／搜索失败或持久历史与当前运行时不一致               |

模型／分词器缺失沿用词法和标签降级；完全失败时不注入资料，继续最近上下文与摘要。来源变化引起的旧请求取消属于会话保护，不能继续使用已失效资料生成回答。

超时后已经开始的本地推理不能强制中断，后台任务可以继续完成派生索引和缓存；共享信号量将此类工作限制为 1 个，后续请求返回 `busy`，迟到结果不会重新注入或补发旧回复。

当前只检索已保存历史与角色笔记；未绑定存档时连同笔记一起跳过，不自动创建存档。尚未落盘的新增旧台词将在保存后的后续请求进入检索。自动保存或手动保存决定何时具备这些历史。首次大规模建索引可能先超时，后续请求复用后台完成的索引。

P6 的自动日记生成尚未实现；已有合法日记索引可以被检索。此阶段没有远程聊天模型或桌面 UI 的端到端实聊验收，大规模性能和发布验收仍属于 P7。
