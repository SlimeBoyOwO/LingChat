初始 受理后进入扫描 扫描 判定这一格怎么处理 赶路 寻路模块内部（复合状态） 放置间隔 收尾 正常迁移 走不通 记原因，歇一下再扫
主循环 扫描直接放下一块 → 放置间隔 → 扫描；扫描叫寻路 → 赶路 → 到站试放 → 放置间隔 → 扫描。
赶路是复合状态 里面的规划与腿是寻路自己的状态机；建筑只等两个结果——到站，或者走不通并带回原因。
中断（不经过选格） 被抱走、昏迷、被别的指令顶掉时直接收尾；收尾里先走到远处的实地，再把垫脚拆净。

扫描与判定 BuildPhase.SCAN → BuildPlanner.work 冷却结束、本层换过顺序 取一格判定：挖掉、就地放，或下发寻路目标 放下 → 间隔；要站位 → 赶路；本层扫完 → 执行决策表或收尾
赶路 BuildPhase.PATHING → Navigator 拿到「站到能放下这一格的位置」的目标与边界 规划选手段，执行一条腿；腿结束再规划 到站 → 试放；走不通 → 把原因翻回格子账，歇一下回扫描
放置间隔 BuildPhase.PLACE_COOLDOWN 刚放下或刚走完一段 倒数几 tick，顺手把走开的垫脚块拆掉 间隔结束 → 扫描
收尾 BuildPhase.DONE → Navigator（NavGoal.Settle） 图纸扫完、超时或被打断 走到实地站好，拆净垫脚，把料还回背包 推 maid_build_done，会话结束
