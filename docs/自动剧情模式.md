# 自动剧情模式

## 概念

自由对话中主要只有 `AI` 和 `玩家` 两个对象。顶多偶尔加一点其他角色。上帝Agent（也被称为`导演`，后续我们称为`导演Agent（异步）`，是上帝Agent的一种变体，比如现在上帝Agent的变体有`好感Agent（异步）`,`选人Agent（同步）`）只有在剧情模式中才会操作游戏，而且剧本是之前写死的内容

为了让剧情更加“AI开放式”，加上工具函数的基石也搭建完毕了。现在允许上帝Agent导演执行以下功能：

1. 玩家可以开启`自由剧情模式`，自由剧情模式下，上帝Agent会随时调用剧本事件，对游戏世界进行操作
2. 首先，会为`上帝Agent（导演）`注册所有剧本事件的工具函数，比如插入旁白，转换场景，切换角色，操作舞台等。
3. 每对话一段时间，`导演Agent`会根据对话内容生成一段`小剧本`，添加旁白为对话引入新的变量，调用工具函数，对游戏世界进行操作。
4. 前端右边侧栏可以打开与`导演Agent`的对话窗口，方便玩家查看导演思路，也可以引导导演安排自己想要的剧情走向。

## 实现步骤

### 1. 在前端新增一个侧栏，用于显示与`导演Agent`的对话

首先做好侧边栏，定义好`导演Agent`的上下文窗口，先把`Agent`对于剧本的感知，基础的玩家对话问答给做出来。

### 2. 将所有剧本事件注册为工具函数，这些函数可以由`导演Agent`调用

把本项目的所有剧本事件注册为工具函数，这些函数可以由`导演Agent`调用。如果玩家和`导演Agent`对话希望安排剧情，`导演Agent`会调用这些工具函数，对游戏世界进行操作。

### 3. `导演Agent`根据对话内容生成一段`小剧本`

提供`导演模式开关`，开启状态下，每过X轮对话，`导演Agent`会根据对话内容生成一段`小剧本`，大约在10个事件左右。

## 项目基础

### 1. 剧本事件概念

本项目的前端的变化由后端发送的事件来驱动，这些事件被称为`剧本事件`，在`crates\ling-chat-main\src\ai_service\game_system\script_engine\events`。在自由模式中，由后端推送的事件主要有：

1. `AI对话`：也就是`dialog_event`事件，主要用于推送`AI`回复的内容
   而剧情模式中，包含更多剧本模式事件。（这提醒我了，能不能自由模式中的切换角色，切换场景，切换特效之类的东西，统一走这里的事件引擎统一逻辑呢？）

也就是说，只要后端发送这些事件，就完成了对游戏的操作。

### 2. 台词表概念

`LingChat`对各Agent驱动的核心由台词表构成，上帝Agent的感知上下文可以参考好感度系统，选人系统等。
