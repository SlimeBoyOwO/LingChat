# 暮色节拍 MIDI 配乐来源

## 真っ黒フランドール S

本曲按提供的 `真っ黒フランドール S 修正版.mid` 制作，界面采用文件中的曲名，不标为项目原创曲。它是东方相关的 MIDI 改编谱；原曲及已有改编的权利归对应作者，转换与程序合成不改变这些归属。源文件未填写可确认的 MIDI 编曲者姓名，因此不推断署名。

- 源文件 SHA-256：`cd91433d9d14fd440591ac1f5296fae344c0a275e44550f5f51fcd26d7dee073`
- MIDI 内部标题：`あの真黒フランドール・Sをうp主が数十人で弾けるような楽譜にしてみた`
- MIDI 原版权文本：`Copyright (C) 2009 `
- 参考文件为 Format 1、480 PPQ、28 轨，其中 26 轨有音符；共 21,190 个音符、17 个速度事件。它是黑乐谱，仅用于分析，不作为完整配乐打包。
- MIDI 本体时长约 212.617 秒；游戏加入四拍准备和 1.8 秒尾声，总长约 215.560 秒。

`src/assets/minigames/twilight/flandre-score.json` 只保存整理后的单声部旋律、独立和弦方案、速度图和来源信息。原 MIDI 的完整轨道事件不保存在游戏资源中。

## 旋律与和声整理

- 每小节优先使用 Main Melody 1，缺席时从后续主旋律声部接续；取稳定旋律音，剥离长音下的十六分震音和密集装饰。起音简化到八分网格，旋律音符之间不重叠。
- 八度调整保留音级，并优先保持相邻旋律的小音程走向。极高、极低的重复被放回可听的旋律音区，力度限制在 72–102；最终保留 785 个单声部旋律音符。
- 原有 Chord、Base、Other 声部均不参与配乐。新和声只根据整理后的旋律计算：以持续时间和重拍为权重，在大小三和弦及减三和弦中选择，优先保留共同音；以半小节为最短和声单位，合并相同和弦，共 192 个和声区间。
- 播放器在中低音区为三和弦选择平稳转位，并另外生成根音/五音低音；减三和弦使用减五音。旋律、和弦、低音三个部分的音色、包络和音量分别控制。
- 四键谱面直接使用整理后的旋律起音与时值，和弦变化的强拍添加双押。共 868 个音符、83 组双押、21 个长按，与配乐同步。

和声处理参考 [Comprehensive Musicianship 的旋律配和声章节](https://iastate.pressbooks.pub/comprehensivemusicianship/chapter/11-5-harmonizing-a-melody-with-non-chord-tones-tutorial/)：用和声节奏区分稳定音与经过音，避免每个装饰音都触发新和弦。该规则用于本项目的自动整理，和弦方案可以在重新导入时调整。

## 重新整理

使用带 `mido` 的 Python 环境，在仓库根目录运行：

```sh
python scripts/import-twilight-midi.py "path/to/真っ黒フランドール S 修正版.mid" src/assets/minigames/twilight/flandre-score.json
```

工具先用同音 FIFO 配对读取参考 MIDI，再提取旋律并重新配置和声；输出不会包含原始轨道数组。遇到不同乐器、控制器或弯音会报错，要求单独处理编配。Python 与 mido 仅用于离线整理；播放器和安装后的主程序不依赖它们。原 MIDI 不需要放进运行目录。
