# 角色可视化编辑

## 差分管理

入口：角色配置 → 差分管理。

- 按默认服装或命名服装展示头像和情绪立绘；服装来源合并配置中的服装和磁盘扫描结果。
- 兼容现有 `avatar/<情绪>.<扩展名>`、`avatar/<服装>/<情绪>.<扩展名>` 结构。
- UI 显示“哭泣（伤心）”“难为情（羞耻）”，实际文件名沿用运行时映射的 `伤心`、`羞耻`。
- `平静` 缺失时显示 `正常` 的回退预览，回退图片不能从平静卡片删除。
- 上传支持 PNG、JPEG、WebP，最大 20 MB，边长最大 8192 像素；后端限制解码内存为 256 MB。
- 上传后统一存为 PNG，临时文件写入成功后替换目标，并清除同情绪其他格式；删除会移除该情绪的所有支持格式。
- 图片操作立即保存，与底部的角色配置保存按钮独立；删除前显示确认。
- `character:avatars-updated` 携带角色 ID；主对话、桌宠重新解析立绘并更新缓存版本。

后端在 `crates/ling-chat-main/src/api/character_avatars.rs`，命令注册在
`src-tauri/src/app/commands.rs`。通过角色 ID 查询资源目录，校验服装路径和符号链接，
支持沿用现有主角色、插件角色和剧本角色的目录解析规则。

## 游戏立绘与气泡布局

入口：角色配置 → 视觉效果。画布支持横屏 1280 × 720 和竖屏 720 × 1280，
可以选择服装与情绪检查效果。静态立绘与游戏使用同一份 `avatar-layout.ts` 取景、
窄屏补偿和布局公式；Live2D 使用实际的 `Live2DStage` 渲染。

- 拖动调整立绘像素偏移，拖动虚线框调整气泡百分比位置，按当前画布缩放换算坐标。
- 滚轮、滑块调整缩放；方向键微调所选项，Shift 加速。
- 可以重置立绘或气泡，并保留下方原有数字输入框精确编辑。
- 画布中的服装、情绪与横竖屏切换只影响预览，不改变游戏当前状态。
- 点击底部保存后，前后端的已加载角色布局同步更新，后续初始化保留新布局。

验证布局计算：`node scripts/test-avatar-layout.mjs`。

## 服装资源管理

入口：角色配置 → 服装。卡片合并配置服装和磁盘目录，展示正常立绘、静态差分完整性、
缺失情绪，并可直接跳到此服装的差分管理。提示词和 Live2D 模型映射可在卡片中编辑。

新增、重命名和移除会连同弹窗内当前角色设置立即保存：

- 新增建立对应的 `avatar/<服装>` 目录和服装配置。
- 重命名同步目录、默认服装、当前穿着、会话覆盖、Live2D 映射和触摸区域；兼容旧格式的 `clothesName`。
- 移除清理对应映射，当前穿着回退默认。原素材移入角色目录的 `.editor-trash/costume-*/<原服装名>`，可手动找回。
- 默认服装保留；目标名称或映射冲突时拒绝覆盖。配置保存失败时恢复目录。
- 资源操作与差分增删使用共享异步锁，避免上传图片时目录被重命名。

## 桌宠布局

入口：角色配置 → 桌宠。预览舞台大小使用全局桌宠缩放（`210 × pet.scale` 像素），
可以切换服装、情绪、圆框和无框模式，拖动立绘、滚轮或滑块缩放、方向键微调和重置。
虚线展示方形舞台边界，静态立绘淡色轮廓展示裁切部分。

静态预览沿用桌宠的 `scale(scale_p) translate(offset_x_p, offset_y_p)` 和顶部偏移；
Live2D 使用实际桌宠舞台。两种模式的偏移缩放顺序不同，拖动时分别换算。
保存会同步前后端运行时的桌宠缩放、偏移和显示方式。

## Live2D 调试

入口：角色配置 → Live2D。编辑模型旁的独立舞台可以演示情绪绑定、重播当前情绪、
单独应用模型表情或播放一次动作；每个已启用部位提供表情/动作测试按钮。
测试使用此预览实例的模型，不发送全局事件，不切换游戏角色情绪。

焦点锚点用十字标记显示，可以在模型边界内点选，写回相对模型边界的归一化坐标；
保留数字输入和恢复中心按钮。锚点及触摸绑定编辑会使几何缓存失效，即时刷新预览。
模型切换会清理调试状态，加载失败时禁用测试。宽屏预览旁置并可独立滚动，窄屏置顶。
保存角色配置后绑定及锚点生效；独立表情与动作选择仅供测试，不写入设置。

## 角色语音试听

入口：角色配置 → 语音。保留现有各服务的配置字段，在表单下方增加试听面板：

- GPT-SoVITS 可选择本机参考音频或读取已填路径，在原生播放器中预听，显示大小与时长。
- 路径仍按 GPT-SoVITS 服务器文件系统解释；远程服务器路径可手填，本机读取失败不妨碍服务端合成。
- 文件选择沿用现有语音字段的防抖自动保存；文本试听使用面板当前参数快照。
- 试听支持 1–500 字符及情绪选择，不翻译文本；支持情绪的服务消费所选标签。
- 所有已有 TTS 类型复用角色 `VoiceMaker` 的适配器、全局服务配置、语言、方言及本地开关/云端回退规则。
- 试听独立构造 `VoiceMaker`，直接返回音频字节，不生成聊天缓存文件或改动聊天 Provider 失败计数。
- 同时只允许一条试听合成，最长 120 秒；参考音频及返回音频上限 20 MB。
- 合成失败显示具体错误；配置或文本变化后标记旧结果。离开面板停止播放并释放音频 URL。
- 音频通过原生播放控件播放，不自动播放；远程服务按其规则接收文本和计费。

后端在 `crates/ling-chat-main/src/api/character_voice.rs`，包含本机音频读取、文本边界和
模拟 HTTP TTS 参数传递测试。Android 文件读取复用现有 SAF 暂存桥接并清理临时副本。

## 触摸区域测试

入口：角色配置 → 触摸 → 打开区域编辑器 → 测试触摸。
测试使用同一份图片归一化坐标、取景换算和多边形命中算法；点击后高亮首个命中部位，
展示全部重叠命中的配置顺序、坐标及将发送的提示词。空提示词的玩家名回退与游戏共用。

测试不发送系统消息、不调用 AI、不改动区域配置；顶点、区域编辑和撤销暂时禁用。
未闭合草稿保留但不参与命中；返回编辑或按 Escape 可继续绘制。服装切换清除上次测试点。
窄屏下画布和侧栏上下排列，侧栏可独立滚动。

验证运行时首命中与编辑器重叠列表的一致性、默认消息和序列化后顺序：
`node scripts/test-touch-regions.mjs`。

## 角色台词示例卡片

入口：角色配置 → 提示词。普通与旧版双语示例均提供消息卡片和原文编辑视图。
卡片支持角色台词增删、上下排序及最近 20 次卡片操作撤销。
新增后自动聚焦正文，首末台词禁用不可用的移动按钮。
后端将这些文本拼接到系统提示词，作为角色性格参考，不解析为 user/assistant 多轮消息；
因此编辑器不提供对话身份切换或用户消息新增。已有标签作为原文前缀展示并保留。

仍写入原来的 `system_prompt_example` / `system_prompt_example_old` 文本字段，
不增加后端格式。解析兼容编号台词、用户/角色或当前名字标签、无标签文本、前置说明、
多行和 CRLF。切换视图不更新文本；未编辑的标签、情绪、动作、翻译与换行原样保留。
新增台词使用数字编号；增删和排序后重排已有数字编号。
底部保存后沿用原来的系统提示词拼接链路生效。

验证无损解析、编辑、标签身份和排序：`node scripts/test-dialogue-examples.mjs`。

## 实施与验证

以上八项按独立功能提交。角色配置继续使用现有半透明面板，保留数字精调和原文编辑。
前端类型检查、生产构建及相关格式检查通过；后端命令通过桌面壳 `cargo check -p ling_chat`
和库测试验证。布局、Live2D、语音、触摸和示例编辑器分别进行了浏览器交互检查。
Live2D 使用官方真实示例模型；语音页面使用测试音频，后端通过本机模拟 TTS 验证参数传递。
真实语音服务合成效果仍取决于用户配置的服务、模型和音色。
