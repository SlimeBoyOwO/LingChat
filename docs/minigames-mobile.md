# 小游戏移动端适配

两款小游戏共用主程序的「开始游戏 → 小游戏」入口，在 Android/iOS WebView 中使用 Canvas、Pointer Events 与 Web Audio，不依赖桌面键盘或外部网页。无需锁定屏幕方向。

手机按钮仅在 Android、iPhone、iPad 上显示，包含以桌面模式访问的 iPadOS。Windows/macOS 不显示手机虚拟按键，触摸屏和窗口宽度不会单独触发这些按钮；桌面继续使用键盘。

| 游戏     | 触摸操作                                               | 画面                                                                                  |
| -------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| 暮色节拍 | 四键点按、长按、多指和弦；点击暂停和调校               | 竖屏全宽谱面，角色与成绩置顶；触摸横屏加宽轨道；按键目标至少 48 像素                  |
| 星灯远征 | 左手移动，可滑动换向；右手跳跃、按住射击；支持同时操作 | 竖屏保留至少 480 世界像素横向视野，纵向延展背景；方向与动作按钮分列下方，至少 56 像素 |

HUD、触摸按钮和弹层继承主程序注入的 `--safe-area-inset-*`，回退到浏览器 `env()`，避开刘海、状态栏与 Home 指示器。手机横屏的暂停菜单采用两列；商店、护甲、说明、调校与结算弹层在空间不足时内部滚动。游戏页面本身不滚动。

每个手指独立记录。松开、系统取消手势或失去指针捕获时释放对应动作；暂停、旋转屏幕和离开路由时清理全部输入。切换后台或系统挂起/中断音频时暂停，用户点击继续后恢复音频；音游保留三拍恢复倒计时。键盘操作继续可用。

星灯远征会将跳跃和射击的极短点按保留到下一个物理步，避免按下与松开都发生在两帧之间时丢失输入。
