# 剧本 Agent（预留设计）

状态：**未实现**，本文只定形态与边界，等自动剧情模式的步骤二（剧本事件注册为工具）、步骤三（定期生成小剧本）落地时再按此推进。代码位置预定 `ai_service/god_agent/script/`，与导演并列。

## 职责

在自由对话里按节奏产出「小剧本」：读最近若干轮的真实对话与现场，写一段大约 10 个剧本事件的安排——插旁白、换场景、换背景或氛围、调动在场角色、操作舞台——再用步骤二的剧本事件工具逐个落地。

它只负责**节奏**（什么时候给剧情加变量），不负责玩家意图（那是导演的活），也不改玩家台词、不替角色说话。产出的每个事件都走和导演相同的工具入口，世界状态的修改方式完全一致。

## 上下文存储构成

**持久层（小剧本历史）**

- 复用通用会话表 `agent_conversation` / `agent_message`，新增 `kind = 'script'`，带 `save_id`，一档一条线；自由对话只在内存；
- 一次生成落一条 assistant 消息：正文 = 这段小剧本的设计说明（为什么这样安排），`tool_calls` = 事件调用，`tool` 消息 = 每个事件的执行结果。下一轮装配时能同时看到「上一段怎么设计的」和「有没有执行成功」，天然避免重复安排同一个转折；
- 不新开表，也不写进角色台词表——小剧本不是台词，不进角色记忆。

**临时层（现场）**

每轮现算，结构与导演的四段装配同构，只换人设：

| 分段     | 内容                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 编剧人设 | 身份描述 + 本轮要产出多少事件、只能从剧本事件工具里选                  |
| 当前现场 | 与导演共用同一份现场快照（模式、时间、场景、背景、氛围、天气、发言者） |
| 在场角色 | 与导演同源，额外带是否在舞台                                           |
| 最近对话 | 最近 `recent_window` 条台词                                            |
| 上文剧本 | 最近一到两段小剧本的设计说明与执行结果                                 |

历史裁剪、工具配对清洗直接复用导演层的实现，不重写。

## 生命周期

- **归属**：交互会话分支的第二种形态。持有会话、落库、流式推事件，但**没有玩家输入**——触发来自对话节奏。实例由 `GodAgentCore` 持有，与导演共用 LLM 槽位和剧本事件工具注册表。
- **运行条件**：一次只跑一段；运行中不启动新的。失败、工具全部失败、取消都不重试，游标照常推进，宁可少给一次变量也不要形成重试风暴。
- **与主线的关系**：落地工具会改世界状态，必须与玩家回复错开——在生成锁空闲后执行，事件只在没有正在推流的回复时下发，避免场景在角色说话途中被切走。生成期间玩家又发了消息，等待而不是抢占。
- **停用**：导演模式开关关闭、剧本模式、没有可用 LLM 时整条线不启动；不影响选人与好感度。

## 调用时刻

全部在生成循环结束后判定，不在生成前抢占舞台：

1. 自由对话模式（`script_status` 为空）；
2. 导演 / 自动剧情开关开启；
3. 台词表里真实对话累计达到阈值（`script_eval_interval`，形态仿好感度游标的 `affection_eval_cursor`，只计真实台词）；
4. 上一段小剧本已经落地完成（没有未收尾的工具调用）。

四个条件都满足才起一次生成；产出一段约 10 个事件，落地后把结果广播给前端（旁白照常进台词表，场景与舞台变化走既有事件引擎）。

## 与导演的边界（待定项）

`docs/自动剧情模式.md` 的步骤三写的是「导演 Agent 每过 X 轮生成一段小剧本」，与本文拆成独立分支有重叠。建议：

- 步骤二先把剧本事件工具注册给导演，玩家可以主动让导演操作世界；
- 步骤三如果节奏生成只是「导演的一个定时任务」，就先做成导演内部的独立运行位（同样的装配、同样的工具、强制非流式或推事件到侧栏），不急着拆目录；
- 出现第二个独立会话需求（比如需要单独的历史线、单独的开关与模型档位）时，再按本文拆成 `god_agent/script/`，复用导演的运行器与装配函数。

现在不抽 trait、不建分支注册表——等这段真的动工，拿导演和剧本两个样本再提炼共性。
