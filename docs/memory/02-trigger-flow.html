这是同步函数，由 role_manager::sync_memories 在持有 GameStatus 锁的情况下调用——而 GameStatus::add_line 每追加一条台词就会走一次。右侧列出全部 8 个静默 return 点： 它们都不写日志（或只写 debug，而默认过滤器是 warn,ling_chat_lib=info）， 所以"阈值设成 250 却从不触发"在日志上与"卡在 is_updating"、"卡在冷却"完全无法区分。 唯一的正向信号是 :408 那条 info!——注意它打在 CAS 之前。
