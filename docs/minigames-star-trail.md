# 星灯远征

入口：**开始游戏 → 小游戏 → 星灯远征**。

像素横版跳跃射击游戏，包含三关和三个 Boss。角色、敌人、地形、背景、粒子及 UI 图形由 Canvas 代码绘制；关卡音乐、Boss 音乐和操作音效由 Web Audio 振荡器合成，无新增图片、音频文件或第三方游戏运行库。

## 操作

- `A / D` 或 `← / →` 移动。
- `W / ↑ / Z` 跳跃，松开按键降低跳跃高度；支持离开平台后短暂补跳及落地前的跳跃输入缓冲。
- 空格连续射击，跳到普通敌人头顶可以踩击。
- `Esc` 或右上角「暂停」打开场景内菜单；可以继续、从检查点重试、返回标题或退出小游戏，并调整音乐与音效音量。
- 屏幕下方的方向、跳跃和射击按键支持触摸及指针操作。
- 收集星晶得分，药瓶恢复生命；点亮检查点会恢复生命，失败后可从检查点重试。已经收集的星晶在重试时不会重复出现。

## 关卡

| 关卡     | Boss     | 攻击                   |
| -------- | -------- | ---------------------- |
| 青苔海岸 | 苔冠守卫 | 蓄力跳跃、落地双向震波 |
| 落日机坊 | 炉心机甲 | 扇形射击、横向冲刺     |
| 星月高塔 | 蚀星魔像 | 浮游弹幕、预警落星     |

Boss 半血后强化攻击。击败 Boss 后前往右侧终点星灯进入下一关，第三关结束后显示总得分、星晶与重试次数。悬空平台可以从下方穿过、从上方落地。

## 实现

- `src/minigames/star-trail/levels.js`：地图、敌人和收集物布局。
- `core.js`：固定 120 Hz 模拟、碰撞、输入缓冲、射击、伤害、检查点和 Boss 状态机。
- `render.js`：程序化像素绘制及视差背景；画布随窗口比例调整，保持像素比例。
- `audio.js`：三套关卡旋律、Boss 旋律与合成音效；短前瞻调度，暂停时停止音符并挂起音频上下文。
- `game.js`、`template.html`、`style.css`：满窗口场景、菜单、输入、HUD、音频及生命周期管理。
- `StarTrail.vue`：懒加载路由组件，在主窗口中挂载游戏并在离开时销毁会话。

音频在玩家开始游戏后创建。失焦或窗口隐藏自动暂停；退出和组件卸载时关闭音频、断开 ResizeObserver、取消动画帧并移除输入监听。玩法不依赖外部服务或剧情状态。

## 验证

- `node scripts/test-star-trail-core.mjs`：运动、大小跳、补跳与输入缓冲、射击、踩怪、受伤无敌、检查点、收集持久性、暂停、三张地图可通行性、三个 Boss 攻击及完整关卡推进。
- `scripts/test-star-trail-browser.cjs`：真实主程序菜单与路由、全窗口布局、键盘与指针输入、死亡重试、音量、暂停/失焦及退出清理。通过 `TEST_ORIGIN` 指定 Vite 地址、`CHROME_PATH` 指定 Chromium 路径。
- `scripts/star-trail-smoke.html`：仅开发使用的控制器检查入口。
