# 星灯远征

入口：**开始游戏 → 小游戏 → 星灯远征**。

像素横版跳跃射击游戏，包含六关路线和一关独立耐久战，共七关、七个 Boss。角色、敌人、地形、背景、粒子及 UI 图形由 Canvas 代码绘制；关卡音乐、Boss 音乐和操作音效由 Web Audio 振荡器合成，无新增图片、音频文件或第三方游戏运行库。

## 操作

- `A / D` 或 `← / →` 移动。
- `W / ↑ / Z` 跳跃，松开按键降低跳跃高度；支持离开平台后短暂补跳及落地前的跳跃输入缓冲。
- 空格连续射击，跳到普通敌人头顶可以踩击。
- `Esc` 或右上角「暂停」打开场景内菜单；可以继续、从检查点重试、返回标题或退出小游戏，并调整音乐与音效音量。
- 标题「关卡选择」可直接练习任意关卡；暂停、失败或结算菜单中的「跳关 / 关卡选择」可保留装备和星晶切换关卡。Esc 可关闭选择界面，按住 Esc 不会重复开关暂停。
- 屏幕下方的方向、跳跃和射击按键支持触摸及指针操作。
- 手机虚拟按键仅在 Android/iOS 显示；Windows/macOS 桌面隐藏它们，包括带触摸屏的 Windows 电脑与窄窗口。桌面操作说明继续显示键盘按键。
- 手机可同时按住移动、跳跃和射击，左手可在方向键之间滑动换向。竖屏保留至少 480 世界像素的横向视野，增加纵向场景空间，避免画面拉伸；横屏沿用侧向视野。按键、护甲入口和菜单避开系统安全区，弹层支持内部滚动。旋转屏幕时自动暂停并释放输入，点击继续恢复。
- 收集星晶得分并增加购物余额；药瓶恢复至多 2 格生命，满血拾取也会消耗药瓶并奖励 50 分。点亮检查点会恢复生命，失败后可从检查点重试。已经收集的星晶和药瓶在重试时不会重复出现。

## 道具、商店与护甲

- 踩弹簧自动高跳；空格射击或从下方顶开补给箱可获得道具。
- 护盾优先抵挡一次伤害，最多储存两次；连射核心提高射速 12 秒，磁力星吸引周围星晶 10 秒。强化剩余时间显示在 HUD，暂停期间不计时。
- 暂停菜单可以打开星灯商店；关卡中的商店位于检查点附近，靠近后按 `E` 或点击提示也能进入。
- 商店使用星晶余额，提供药瓶（4）、护甲修复（5）、护盾（6）、连射（6）、磁力（5）及护甲升级。不能购买时明确显示满血、护甲完好、满级或缺少的星晶数量。
- 点击生命条下方的护甲条，或选择暂停菜单中的「护甲装备」，可查看等级、当前护甲值与升级效果。
- 护甲有旅人护甲（2 点）、巡星护甲（4 点，升级 10 星晶）、辉光护甲（6 点，升级 18 星晶）三级。默认装备旅人护甲，升级自动装备并修复；受伤时按临时护盾、护甲、生命的顺序扣除防护。
- 护甲等级和购物余额在当前远征的关卡切换与重试间保留；重试会修复护甲，临时强化会重置，临时补给箱重新可用。重新开始远征会重置装备与余额。

| 落日机坊 | 炉心机甲   | 扇形射击、横向冲刺                         |
| 星月高塔 | 蚀星魔像   | 浮游弹幕、预警落星                         |
| 霜风断桥 | 霜刃猎手   | 精准跳跃、间歇霜息，更快的扇射与冲刺       |
| 雷鸣回廊 | 雷铸巨像   | 高电阵、交错炮火，落地震波与预警落星       |
| 熔星裂谷 | 熔翼守望者 | 密集路线、熔焰机关，强化扇形星弹与连续落星 |
| 永夜星核 | 永夜星核   | 90 秒三阶段耐久，护盾解除后击破核心        |

普通 Boss 半血后强化攻击。击败 Boss 后前往右侧终点星灯进入下一关，第七关结束后显示总得分、星晶与重试次数。悬空平台可以从下方穿过、从上方落地。后三关路线保留检查点、商店和补给，增加较窄的平台、更紧密的敌人配置和不同相位的周期机关；机关有一秒预警、一秒喷发，其余时间可安全穿行，高电阵也可等待关闭或经平台绕过。

永夜星核在激活后开始计时，前三十秒为「星潮」、中间三十秒为「交织」、最后三十秒为「极夜」。攻击交替使用提前瞄准的扇形星弹、侧面震波与有落点预警的星雨；星雨的空缺位置以地面绿色标记提示，其他攻击仍需躲避。三十秒和六十秒时清理当前弹幕，提供短暂喘息和场中药瓶。撑过九十秒后护盾解除，随后击破 96 点生命的核心并走到右侧出口才算完成。

耐久期间射击不会扣除 Boss 生命，护盾命中会闪光；HUD 明确显示护盾状态、阶段、剩余秒数及倒计时条。暂停、商店和关卡选择期间计时停止；重试从检查点重新开始完整耐久战，清空旧弹幕和阶段状态，并按新一轮阶段重新提供场中补给。射击、移动与跳跃仍可同时进行，音乐继续使用 kawaii bass 风格的代码合成音色。

## 关卡选择与跳关

所有关卡直接开放。标题选择关卡时开始一次独立练习：前三关为旅人护甲、零星晶，第四关为巡星护甲和 10 星晶，第五关为巡星护甲和 14 星晶，第六关为辉光护甲和 14 星晶，耐久战为辉光护甲和 18 星晶。

暂停等菜单中跳关会保留现有护甲等级、星晶余额、得分与重试次数，恢复生命和护甲，清除原关卡的检查点、收集状态、临时强化、子弹、弹幕与预警。HUD 和结算会标记「练习」，从中途进入最终关不会显示为完整远征通关；重新从标题「开始远征」出发则恢复普通七关流程。选择界面支持键盘、触摸与弹层内部滚动，横屏短窗口使用两列。

## 实现

- `src/components/views/minigames/star-trail/levels.js`：地图、敌人和收集物布局。
- `core.js`：固定 120 Hz 模拟、碰撞、输入缓冲、射击、伤害、检查点、周期机关和 Boss 状态机；Boss 行为按关卡指定的类型选择，耐久逻辑独立管理阶段和护盾。
- `render.js`：程序化像素绘制及视差背景；画布随窗口比例调整，保持像素比例。
- `bgm.js`、`audio.js`：原创 kawaii bass 风格配乐，包含铃音主旋律、失谐锯齿七和弦、切分低音、底鼓、噪声拍手与踩镲、鼓点压低和弦音量的律动。七关分别为 144 / 150 / 140 / 154 / 160 / 166 / 150 BPM；前三关 Boss 为 164 BPM，新增路线 Boss 为 168 BPM，耐久 Boss 为 174 BPM。全部通过 Web Audio 代码合成，不需要采样文件；短前瞻调度，暂停时停止音符并挂起音频上下文。
- `game.js`、`template.html`、`style.css`：满窗口场景、菜单、输入、HUD、音频及生命周期管理。
- `StarTrail.vue`：懒加载路由组件，在主窗口中挂载游戏并在离开时销毁会话。

音频在玩家开始游戏后创建。失焦或窗口隐藏自动暂停；退出和组件卸载时关闭音频、断开 ResizeObserver、取消动画帧并移除输入监听。玩法不依赖外部服务或剧情状态。
