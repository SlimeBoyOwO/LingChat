# LingChat v0.5.0

## [0.5.3] - 2026-10-26

## 🐈 更新主题：动态Live2d, 自定义摸摸，mc女仆联动，TODO 增强，语音聊天，自动纠错，一键新建角色

### 🎉 更新内容详解：

#### ✨️ Part 1: Live2d支持，无框桌宠

- **Live2d演出**：现在你可以导入任意 Live2d 模型对话啦，live2d 角色支持自定义情绪和动作同步演出！
- **摸摸机制**：摸摸机制复活啦，现在可以自定义你的触摸区域和触摸提示词在设置中~
- **无框桌宠**：如果桌宠是live2d，你可以把它设置为无框桌宠，以更简洁的方式显示在桌面上陪伴
- **新角色**：新增了一个来自一位贡献者的角色：松子！

#### 🧀 Part 2: 联动 mc 世界，新增角色

- **AI 女仆**：新增了可以和 mc 联动的女仆插件，开启插件后你可以和你的东方女仆联动lingchat一起在游戏世界冒险
- **世界感知**：在 mc 中的角色可以感知周围的环境并且主动与你做出反应。
- **动作执行**：我们为 mc 里的女仆初步增加了几个动作，可以指示她干活捏
- **插件功能**：插件功能大幅增强，希望各位能开发自己的插件与lingchat联动！（如QQ bot）

#### 🌈 Part 3: TODO 增强，音乐频谱&桌宠播放器，语音

- **TODO增强**：现在代办支持添加截止日期，可以设定多少时间之前提醒自己，并且增加代办小组件在桌面上可以快速查阅。
- **音乐频谱**：播放音乐的时候可以显示屏频谱，转换成桌宠就是一个酷炫的音乐播放器了哦
- **语音聊天加强**：现在可以接入阿里的 ASR，与 AI 进行语音聊天，增加了短词模式可以与 AI 随时聊天互动哦。

#### 🌸 Part 4: 语音聊天，对话增强与纠错

- **手机也可以玩 TTS**：现在手机也可以通过内置 TTS 引擎来体验语音了！
- **内置语音引擎**：可以在软件内配置语音，从而无需下载额外的 TTS 引擎！
- **上下文自动纠错**：现在软件在检测到 AI 出错的时候会立马进行自动修复或自动纠错，以后你再也不会遇到 AI 格式出错，情绪文本长，动作太多等错误了！

#### 📚 Part 5: 杂项更新

- **文档更新**：主设置界面的文档新增了大量了解软件配置，自定义软件玩法，创意工坊的文档，可以点击查看！
- **大模型提供商**：新增了更多大模型提供商选项，提供默认选项
- **丝滑的切换动画**：现在 UI 切换界面的时候有更流畅的动画
- **手机版bug修复**：修复了大量第一版手机版中反馈的问题
- **自定义对话界面**：新增自定义对话界面样式

### 🔧 Bug 修复与改进

- 上一轮版本几乎没有 `bug` 哦耶，修复了已知的几个小问题

## 使用注意事项（一定要看！！）

Q：下面的那么多文件，我应该下载哪个呢？

A：`setup.exe`的是`win`的安装程序，`apk`则是手机。至于`linux`和`macos`用户选择相应版本即可。

Q：Python 版本呢？

A：Python 版 LingChat 已不再提供发行版，当然，自行从源码部署仍然可以。目前 Python 版本已进入半归档状态，更新不会很活跃。

Q：手机版怎么进去没人物

A：手机版第一次安装进去后，需要退出来重新进入就ok了捏

Q：多出来的 data.7z 是什么

A：如果你是由之前版本更新的，可以下载这个data并解压到软件根目录中，包含官方DLC和剧本编辑器必备内容：

- 新人物：DeepSeek
- 新插件：联网搜索插件
- 官方skills：文件读取，剧本编写，skills示范等
  > 才不是因为发现自动更新有点小bug呢哼（
  > 如果是第一次使用可以无视这个，如果不需要以上功能也可以等 v0.5.1
