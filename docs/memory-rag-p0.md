## 1. 模型资源与实际推理

已执行仓库现有的 `node scripts/download_embedding_model.mjs`，资源保存在 `data/third_party/embedding_model_bge_small_zh/`。采用 `BAAI/bge-small-zh-v1.5` 的 Xenova uint8 ONNX 导出，下载源为 ModelScope 镜像 `Xenova/bge-small-zh-v1.5`，远端路径为 `onnx/model_uint8.onnx`。

这就是合作者所说的约 25 MB 中文模型：主模型为 23,903,404 字节，连同分词器和配置共 24,343,245 字节。它负责把文本转换为向量，完整记忆 RAG 还需要数据范围、索引、检索与聊天接入。

真实测试加载该模型与本地 ONNX Runtime，执行了工具意图和三组记忆语料推理。新增记忆检查要求输出 512 维、所有分量有限、L2 范数与 1 的偏差小于 `1e-3`，且相关文本得分高于无关文本。

模型可正常推理，中文语料具有基本语义区分能力。这几组得分不能用作通用相关性阈值，也不代表长期记忆检索质量已达标。当前引擎最多接受 512 token，超出会截断；P2 的分块必须依据实际 tokenizer，避免依赖截断处理长历史。异步业务调用继续放入阻塞线程池。

模型二进制已确认被 Git 忽略。此处验证的是本机开发资源，桌面安装包的资源路径与发布验收留在 P7。

## 3. 独立数据库与固定验收集

新增文件：

- `crates/ling-chat-main/tests/fixtures/memory_rag/acceptance.json`：合成语料、来源 ID、查询和标签。
- `crates/ling-chat-main/tests/memory_rag_p0.rs`：基于真实迁移的隔离数据库测试与验收标签检查。

每项数据库测试只向 `tempfile::tempdir()` 下创建的数据库与笔记文件写入，结束时关闭连接并清理临时目录，不调用应用数据目录解析器，不读写用户存档数据库。

样例包含 3 个角色（用户和两个聊天角色）、3 个存档、16 份候选文档和 18 条查询。主存档有效链为 44 条，包含 36 条普通闲聊填充，使开头的独有事实离开最近 30 条窗口。另有同存档的失效分支台词、独立存档和另一分支的不同答案，用来检查范围隔离。

候选文档分为原文、手写的日记样例和角色笔记。日记样例只是带源台词 ID 的固定验收素材，当前没有调用 LLM 生成日记，也没有建立日记表。

18 条查询分为 12 条校准样例和 6 条保留复核样例，覆盖旧事实、同义改述、人名、日期、标签、连续指代、角色感知、存档与分支隔离、计划与事实、无关输入、自发言可见性、旧笔记、历史指令引用以及来源去重。每条查询带 `expected_any` 和 `excluded` 文档 ID；引用内容是待检索数据，不能作为当前系统指令。

新增的 3 项测试实际验证：

1. 数据库 `quick_check` 为 `ok`；有效历史和最近窗口正确；普通台词按角色感知隔离，自己的发言仍可见；其他存档历史独立。
2. 文档与查询 ID 唯一；来源存在、原文一致；预期答案位于对应存档的有效链并满足角色可见性；查询标注的正确与禁止来源无冲突。
3. 把主存档指针撤回到第 2 条后，仅返回前两条历史；旧格式笔记仍可读取和保存，两个角色的笔记文件保持分离。

这些是现有范围语义和样例有效性的验证，尚未执行未来混合检索器，也未证明缓存或日记会正确失效。

## 4. 后续质量指标与生命周期验收

P3 使用校准集确定参数，再报告保留集的结果。18 条中 15 条有答案、3 条预期无答案：

- `hit@5`：仅以 `expected_any` 非空的查询为分母，前 5 个结果至少含一个正确来源即记命中；分别报告校准集和保留集的分子、分母，首版目标不低于 90%。
- 无答案误召回率：以 `expected_any` 为空的查询为分母，返回非空片段即记误召回，单独列出失败例。
- 范围违规：任何返回结果越过角色、存档或当前有效链均记失败，包括没有逐条列在 `excluded` 中的来源；所有明确禁止来源必须零返回。
- 去重：同一源事件的原文与日记不重复占满结果；历史指令引用只作为资料；计划查询仍保留未发生状态。这些需检索与聊天接入后另行检查。

保留集规模很小，适合作为固定回归检查，不用于推断真实用户的整体准确率。P7 再补充脱敏语料与更大规模性能评估。

| 生命周期场景                           | 实施及验收阶段                                 |
| -------------------------------------- | ---------------------------------------------- |
| 有效链、感知变化、撤回源台词           | P1 定义范围；P2/P4/P6 验证索引、缓存与日记失效 |
| 编辑源文本、复制或删除存档、切换模型   | P2 建立版本及重建；P7 完整复核                 |
| 更新、删除、外部编辑旧笔记             | P2 索引同步；P4 缓存失效；P7 复核              |
| 查询重复、缓存触碰、满容量淘汰         | P4 实测 LRU、调用次数与永久数据保留            |
| 异步检索时切换存档                     | P5 最终发送前复核                              |
| 日记生成期间撤回、切换、重启或失败重试 | P6 校验提交版本、幂等与恢复                    |
| 模型缺失、推理失败、超时、无关问题     | P3/P5 词法降级与正常聊天；P7 完整复核          |
