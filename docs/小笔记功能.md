# 信纸：画画与公式、代码展示功能

## 概念

现在 AI 缺少一种给玩家展示自己“画画”的功能，也缺少表达复杂符号比如SVG，或者MD文档比如公式，或者代码的能力。为了补足这个功能，现在特别开发一个前端展示小信纸的功能。当小信纸需要显示的时候（比如 AI 调用了，信纸内容更新了），前端会把人物向侧边移动并显示出信纸内容。AI 写信纸的功能通过工具函数提供给 AI，AI 可以在本信纸中用 MD 语法写出详细内容，用 SVG 画出图片甚至塞入图片（代办，不知道这个功能必不必要），展示代码等。

## 实现步骤

### 1. 在前端新增一个信纸面板，用于显示包含`MD，SVG，图片，代码`的信纸内容

首先在前端做出一个信纸展示部分，这个部分可以显示`MD语法（项目有可复用），SVG，图片，代码`等，并且可以显示在人物旁边。要求：

1. 信纸的弹出和隐藏需要动画效果。信纸弹出的时候，人物向侧边移动，显示信纸内容。信纸的窗口大小可以放大，内部可以放大，滑动内部内容
2. 信纸的样式偏向于小信纸那种样式。默认在人物右侧。
3. 信纸内容更新的时候自动显示，玩家可以手动关闭，此时人物复位
4. 切换人物的时候，信纸内容自动隐藏，人物复位，清空信纸内容
5. 信纸内容可以复制（特指复制md语法），导向源文件，下载，这些功能统一放在 `···` 的图标内再展开。
6. 信纸内容存储到`data/notes`目录下，用`uuid`命名。

为了方便测试，先：

1. 直接把包含md语法的固定文件先拿出来做为固定信纸内容，后端下一期做

### 2. 将`更新信纸内容`作为工具函数，提供给角色AI

把更新信纸 `MD` 内容作为工具函数，提供给角色AI，描述中说明这个工具函数可以画画，演示公式，代码，详细计划书等。后端要求：

1. 注册有关工具函数。
2. 可以查看，编写，更新信纸内容。
3. 数据库中增加存档与信纸的关系。一对多关系，一个存档可以有多个信纸，一个信纸只能属于一个存档。存档数据库记录的是信纸的`uuid`。
4. 和语音wav一样，假如说程序启动的时候发现`data/notes`目录中有没有记录在数据库的信纸，自动删除。
5. 这也要求前端信纸内容可以换页，数据库存储的时候要有顺序记忆。笔记在前端的展示就是一个笔记对应一页，可以翻页。
