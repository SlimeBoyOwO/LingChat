# 果蝇的每一天：主程序小游戏

入口：**开始游戏 → 小游戏 → 果蝇的每一天**（路由 `/mini-games/fly-brain`，懒加载）。菜单项提供简体中文、繁体中文、英语、日语文案；场景内 UI 为中文。

这是一座 3D 牧场生活观察舱：Rust 后端实时仿真 FlyWire v783 连接组的 139,255 个神经元（LIF 脉冲模型），由脑活动驱动一只果蝇在牧场上度过每一天——觅食、进食、昼夜作息。界面沿用主菜单的 Galgame 视觉语言：清新蓝天、白色大字配柔和阴影、圆角半透明控件。场景为青绿山水/水墨风：远山层叠、白雾绕场、一角池塘。

## 玩法

- **观察一只果蝇的日常**：果蝇在荷花与桃子等蜜源之间飞舞、觅食、进食；饥饿与能量在左下角状态卡以细条显示，状态文字在飞舞中/觅食中/进食中/休息中/睡觉中之间切换。
- **程序化 3D 果蝇**：头/胸/腹三个椭球体（腹部环纹）、红色复眼、两片绕胸部连接点扇动的半透明膜翅（飞行约 11Hz，落地收拢后掠），以及**六条腿**——胸节两侧各三条、每条腿股/胫节两节细圆柱；飞行时蜷起悬垂轻摆，落地时撑地站姿，腿部抖动幅度正比于快照的 `brain_activity`（脑越兴奋腿越活跃，即「画六条腿接上神经元」）。N·L 光照随日月光源色与天色变化。
- **「果蝇大脑」小窗**：右上角「大脑」按钮开关。开启后左上角出现圆角毛玻璃小窗，内嵌独立 WebGL2 上下文，渲染 139,255 神经元全脑点云（渲染器复活自 f25008a6 提交：`aPos/aColor/aSpike` 三缓冲、500ms 指数拖尾发光、加法混合、圆形片元裁剪、FlyWire 分类配色）。坐标数据首次开窗时经 `fly_brain_positions` 拉取并缓存，放电事件随 200ms 快照 `spikes/spike_ages_ms` 增量上传，相机固定缓慢自转、纯观赏不可拖拽；关闭即 `display:none` 并暂停渲染与上传。
- **昼夜循环**：太阳东升西落，天空随太阳高度在白天石青白雾、黄昏暖金、夜晚水墨深蓝之间渐变；夜晚有月亮、星星和萤火虫。顶部居中显示时间图标（日出/日/日落/月）与 24 小时制时钟。
- **萤火虫即脑活动**：夜晚萤火虫的亮度与点亮数量跟随 `brain_activity` 呼吸，把真实全脑发放融进场景；右下角署名旁的小圆点也随脑活动脉动。
- **事件 toast**：吃到蜜、入睡等事件从底部浮出淡入淡出（按 `seq` 去重，重新开始后序号重置）。
- **控制**：右上角按钮依次为时间流速（0.5x/1x/2x 循环）、奖惩可塑性学习开关、大脑小窗开关、重新开始、返回。相机默认缓慢环绕并松弛跟随果蝇；左键拖动旋转、滚轮缩放，空闲数秒后恢复自转。

## 视觉通道（复眼接神经元）

快照的 `vision` 字段给出三个 0..1 归一值：`left` / `right` 是左右视觉感觉群（sens_left / sens_right 各约 200 个视觉投射神经元，接收食物方位、危险与光照电流的那群）在近 600ms 的真实放电率归一值，`optic` 为全视叶同步率。两只复眼各自独立发光：平时暗红，对应侧视觉群放电增强时泛起粉红亮光并轻微脉动（亮度与脉动幅度均正比于该侧 `vision` 值）；果蝇状态切入「进食中」的瞬间双眼同闪一下，呼应吃到蜜的事件。左下角状态卡底部有「复眼 L/R」两个小圆点，亮度随同样的值呼吸，便于直接读取视觉神经活动。旧快照没有 `vision` 字段时复眼保持基础暗红，不报错。

## 场景构成（青绿山水）

- **远山三层剪影**：山脊线由 value noise 沿圆周采样生成（闭环连续），三层半径/峰高/颜色由近及远为黛绿 → 石青 → 淡蓝灰，峰顶略内倾形成山坡剪影，山脚深、峰顶浅的烘焙渐变；合并为单次 draw call，与地形共用光照着色器。层间九条半透白雾带（程序化柔边贴图 billboard）缓慢环场漂移、明暗呼吸。
- **池塘水景**：`heightAt` 在池塘处压出浅盆（塘底烘焙泥沙色），水面为圆形 plane：菲涅尔式天色反射 + 波纹微扰 + 日光碎金高光，塘面点缀程序化荷叶与一朵荷花；草叶与装饰自动避让塘区，相机经过塘面时不下穿水面。
- **植被**：竹丛（细高绿杆+叶簇）、松树（层叠伞盖）、桃树（褐干+粉色花团）与少量石头，全部程序化 canvas 贴图 billboard；蜜源为荷花（kind 0）与桃子（kind 1）。
- **配色**：白天石青石绿 + 白雾、黄昏暖金、夜晚水墨深蓝；草地嫩青；距离雾颜色始终跟随地平线天色。

## 运行与资源归属

仿真运行在 Rust 后端的独立线程（圆盘牧场世界：蜜源、觅食/进食/昼夜作息），前端通过 Tauri 命令交互：`fly_brain_enter`（挂载时调用，幂等，首次加载模型并校准）、`fly_brain_state`（200ms 轮询：时刻、太阳高度、果蝇位置/状态/饥饿/能量、蜜源列表、事件、脑活动、放电抽样）、`fly_brain_positions`（大脑小窗首次开启时拉取一次坐标与分类，base64）、`fly_brain_control`（流速、重开、可塑性开关）、`fly_brain_exit`（卸载时停仿真线程）。invoke 拒绝时轮询跳过该帧，不弹错；进入场景先显示「正在唤醒果蝇大脑……」，首个状态快照到达后淡出。

前端沿用主程序小游戏惯例：`FlyBrain.vue` 挂载 Shadow DOM（模板与样式 `?raw` 注入，与全局皮肤隔离），`fly-brain/` 内含场景逻辑、模板、样式与类型声明。渲染为零依赖 WebGL2、全屏单画布（大脑小窗为第二个独立 GL 上下文）：天空穹顶 shader（日月与光晕、黄昏方位晕染）、星星点缓冲、96×96 heightfield 地形（CPU 与着色器共用同一高度函数）、远山合并网格、水面 shader、约 4500 株实例化草叶、实例化广告牌精灵（装饰/蜜源/雾带按深度排序单 draw call）、萤火虫点精灵，以及 CPU 逐帧变换的 3D 果蝇（刚体部位与 12 节腿段合并成一个动态缓冲单次 draw，膜翅另一次透明 draw）；主场景每帧约 12 个 draw call。果蝇位置在 200ms 轮询间隙用 rAF 指数平滑补间。

每次挂载都有独立 AbortController。返回列表、路由切换或页面关闭会取消动画帧、清除轮询定时器、移除全部事件监听、经 `WEBGL_lose_context` 释放主场景与大脑小窗两个 GL 上下文，并调用 `fly_brain_exit` 停止仿真线程；再次进入创建新的会话。

脑模型数据文件为 `data/third_party/fly_brain/graph.npz`（约 18MB），随运行环境分发，`data/**` 已在 `.gitignore` 中排除，不入 git。

### 数据获取（graph.npz 的构建）

`graph.npz` 由 FlyWire Codex v783 公开转储构建（`np.savez_compressed`）：

1. 下载原始 CSV（约 57MB gz）：`https://storage.googleapis.com/flywire-data/codex/data/fafb/783/` 下的 `connections.csv.gz`、`coordinates.csv.gz`、`classification.csv.gz`（备用镜像 Zenodo <https://zenodo.org/records/10676866>）。
2. 构图规则：connections 按 (pre_root_id, post_root_id) 合并多 neuropil 行，丢弃 syn_count<5 的弱连接与自连接，得到 2,484,367 条边；权重 = sign·sqrt(syn_count)·0.3（抑制性突触为负）；坐标与分类按 root_id 对齐到 139,255 个神经元；存储为按 post 排序的 CSR（indices/indptr/weight/edge_nt）加按 pre 排序的出边 CSR（out_indptr/out_edges）。
3. 将生成的 `graph.npz` 放入 `data/third_party/fly_brain/` 即可；文件缺失时小游戏「唤醒」失败并显示提示，不影响主程序其他功能。
