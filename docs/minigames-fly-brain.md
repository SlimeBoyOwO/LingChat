# 果蝇的每一天：主程序小游戏

入口：**开始游戏 → 小游戏 → 果蝇的每一天**（路由 `/mini-games/fly-brain`，懒加载）。菜单项提供简体中文、繁体中文、英语、日语文案；场景内 UI 为中文。

这是一座 3D 生活观察舱：Rust 后端实时仿真 FlyWire v783 连接组的 139,255 个神经元（LIF 脉冲模型），由脑活动驱动一只 Q 版博丽灵梦在博丽神社度过每一天——觅食、进食、散步、昼夜作息。界面沿用主菜单的 Galgame 视觉语言：清新蓝天、白色大字配柔和阴影、圆角半透明控件。场景在青绿山水底版（远山层叠、白雾绕场、一角池塘）上建起纯程序化几何的博丽神社。

## 玩法

- **观察巫女的日常**：灵梦在参道两侧的团子串与赛钱箱（蜜源 kind 0/1）之间飞舞、觅食、进食；饥饿与能量在左下角状态卡以细条显示，状态文字在飞舞中/觅食中/进食中/散步中/休息中/睡觉中之间切换；「复眼 L/R」小圆点下方另有「活跃」行，千分位显示近 600ms 发放过的去重神经元数（快照 `active_neurons`，旧快照缺省显示 —）。
- **Q 版博丽灵梦（程序化建模）**：二头身——黑色长发（发盖半球 + 后长发片 + 侧发绺）、大红白蝴蝶结（双耳 + 结心 + 两条缎带尾）、红白巫女服（白衣上身、红袴白裾）、白色 detached 袖（红袖缘）、小腿小鞋。漂浮时上下浮动、微前倾、袖口裙摆轻摆；散步时小腿交替迈步、身体轻弹；休息坐下、睡觉躺下（身体后仰约 75°）；起落约 0.5s 平滑过渡。**神经元联动**：袖口与蝴蝶结缎带的摆动幅度正比于快照 `brain_activity`（脑越兴奋摆得越欢）；看到食物的一侧眼睛亮起 subtle 白色高光（`vision.left/right`，emissive 不走光照）；进食瞬间双眼同闪。不认识的 state 按 flying 兜底。
- **「果蝇大脑」小窗**：右上角「大脑」按钮开关。开启后左上角出现圆角毛玻璃小窗（透明底点云浮在面板上），内嵌独立 WebGL2 上下文，渲染 139,255 神经元全脑点云（渲染器复活自 f25008a6 提交：`aPos/aColor/aSpike` 三缓冲、500ms 指数拖尾发光、加法混合、圆形片元裁剪、FlyWire 分类配色）。标题栏右侧迷你 pill 按钮切换显示模式（原版两档）：**活动**（uDim=0，只显示近期被激活的神经元，默认档）/**解剖**（uDim=1.1，全脑分类色）。坐标数据首次开窗时经 `fly_brain_positions` 拉取并缓存，放电事件随 200ms 快照 `spikes/spike_ages_ms` 增量上传；小窗内可左键拖拽旋转、滚轮缩放（0.4~5 倍），空闲 3 秒恢复缓慢自转（对齐原版网页交互）；关闭即 `display:none` 并暂停渲染与上传。
- **昼夜循环**：太阳东升西落，天空随太阳高度在白天石青白雾、黄昏暖金、夜晚水墨深蓝之间渐变；夜晚有月亮、星星和萤火虫，参道石灯笼放出暖光晕。顶部居中显示时间图标（日出/日/日落/月）与 24 小时制时钟。
- **萤火虫即脑活动**：夜晚萤火虫的亮度与点亮数量跟随 `brain_activity` 呼吸，把真实全脑发放融进场景；右下角署名旁的小圆点也随脑活动脉动。
- **事件 toast**：吃到团子、捡到赛钱等事件从底部浮出淡入淡出（按 `seq` 去重，重新开始后序号重置）。
- **控制**：右上角按钮依次为时间流速（0.5x/1x/2x 循环）、奖惩可塑性学习开关、大脑小窗开关、重新开始、返回。相机默认缓慢环绕并松弛跟随灵梦；左键拖动旋转、滚轮缩放，空闲数秒后恢复自转。

## 视觉通道（眼睛高光接神经元）

快照的 `vision` 字段给出三个 0..1 归一值：`left` / `right` 是左右视觉感觉群（sens_left / sens_right 各约 200 个视觉投射神经元，接收食物方位、危险与光照电流的那群）在近 600ms 的真实放电率归一值，`optic` 为全视叶同步率。灵梦两只眼睛的高光各自独立调制：对应侧视觉群放电增强时白色小高光更亮并轻微脉动（亮度与脉动幅度均正比于该侧 `vision` 值）；状态切入「进食中」的瞬间双眼同闪一下，呼应吃到团子的事件。左下角状态卡的「复眼 L/R」两个小圆点随同样的值呼吸，便于直接读取视觉神经活动。旧快照没有 `vision` 字段时高光保持基础暗态，不报错。

## 场景构成（博丽神社 · 青绿山水底版）

- **神社本殿**（北侧高台）：石台基 + 三级台阶 + 深红木柱 + 白墙 + 深灰歇山顶（程序化四坡屋顶：梯形坡面分三段刻画檐口角部起翘 + 屋脊与脊端饰）、正面注连绳与四组纸垂、门口赛钱箱（箱顶木缝）与大铃铛（铃架 + 铃绳 + 椭球铃）。
- **朱红鸟居**（南侧参道入口）：双圆柱 + 笠木/岛木双层 + 贯 + 额束，经典明神鸟居比例，柱脚垫基石。
- **参道**：鸟居到本殿的 35 块石板（逐块贴合地形高度，形成自然台阶感），两侧五对石灯笼（基座/竿/中台/火袋/笠/宝珠），夜里火袋处叠暖色光晕 billboard（透明度随夜色呼吸）。
- **底版保留**：远山三层剪影（黛绿→石青→淡蓝灰 + 层间雾带）、池塘水景（荷叶荷花）、实例化草叶、萤火虫、天空穹顶日月星；植被为竹丛、松树与樱花树（参道入口成对 + 散植，淡粉花团）。蜜源 billboard 为团子串（三色团子）与赛钱箱（小木箱 + 金币光点）。
- **配色**：白天石青石绿 + 白雾、黄昏暖金、夜晚水墨深蓝；草地嫩青；距离雾颜色始终跟随地平线天色。参道与社殿高台区域草叶与装饰自动避让。

## 运行与资源归属

仿真运行在 Rust 后端的独立线程（神社世界：蜜源、觅食/进食/散步/昼夜作息），前端通过 Tauri 命令交互：`fly_brain_enter`（挂载时调用，幂等，首次加载模型并校准）、`fly_brain_state`（200ms 轮询：时刻、太阳高度、灵梦位置/状态/饥饿/能量/速度、蜜源列表、事件、脑活动、视觉通道、活跃神经元数、放电抽样）、`fly_brain_positions`（大脑小窗首次开启时拉取一次坐标与分类，base64）、`fly_brain_control`（流速、重开、可塑性开关）、`fly_brain_exit`（卸载时停仿真线程）。invoke 拒绝时轮询跳过该帧，不弹错；进入场景先显示「正在唤醒果蝇大脑……」，首个状态快照到达后淡出。

前端沿用主程序小游戏惯例：`FlyBrain.vue` 挂载 Shadow DOM（模板与样式 `?raw` 注入，与全局皮肤隔离），`fly-brain/` 内含场景逻辑、模板、样式与类型声明。渲染为零依赖 WebGL2、全屏单画布（大脑小窗为第二个独立 GL 上下文）：天空穹顶 shader（日月与光晕、黄昏方位晕染）、星星点缓冲、96×96 heightfield 地形（CPU 与着色器共用同一高度函数）、远山合并网格、神社静态合并网格（本殿/鸟居/石板/石灯笼单次 draw）、水面 shader、约 4500 株实例化草叶、实例化广告牌精灵（装饰/蜜源/雾带/灯笼光晕按深度排序单 draw call）、萤火虫点精灵，以及 CPU 逐帧变换的 Q 版灵梦（刚体部位 + 袖/腿/缎带动态部件合并成一个动态缓冲单次 draw，眼睛高光另一次 emissive 小 draw）；主场景每帧约 13 个 draw call。灵梦位置在 200ms 轮询间隙用 rAF 指数平滑补间。

每次挂载都有独立 AbortController。返回列表、路由切换或页面关闭会取消动画帧、清除轮询定时器、移除全部事件监听、经 `WEBGL_lose_context` 释放主场景与大脑小窗两个 GL 上下文，并调用 `fly_brain_exit` 停止仿真线程；再次进入创建新的会话。

脑模型数据文件为 `data/third_party/fly_brain/graph.npz`（约 18MB），随运行环境分发，`data/**` 已在 `.gitignore` 中排除，不入 git。

### 数据获取（graph.npz 的构建）

`graph.npz` 由 FlyWire Codex v783 公开转储构建（`np.savez_compressed`）：

1. 下载原始 CSV（约 57MB gz）：`https://storage.googleapis.com/flywire-data/codex/data/fafb/783/` 下的 `connections.csv.gz`、`coordinates.csv.gz`、`classification.csv.gz`（备用镜像 Zenodo <https://zenodo.org/records/10676866>）。
2. 构图规则：connections 按 (pre_root_id, post_root_id) 合并多 neuropil 行，丢弃 syn_count<5 的弱连接与自连接，得到 2,484,367 条边；权重 = sign·sqrt(syn_count)·0.3（抑制性突触为负）；坐标与分类按 root_id 对齐到 139,255 个神经元；存储为按 post 排序的 CSR（indices/indptr/weight/edge_nt）加按 pre 排序的出边 CSR（out_indptr/out_edges）。
3. 将生成的 `graph.npz` 放入 `data/third_party/fly_brain/` 即可；文件缺失时小游戏「唤醒」失败并显示提示，不影响主程序其他功能。
