# tauri-plugin-screenshots 本地差异小贴士

> 本插件是上游 [ayangweb/tauri-plugin-screenshots](https://github.com/ayangweb/tauri-plugin-screenshots)
> 的 vendored 副本（普通 git 跟踪文件，**不是 submodule**），通过
> `src-tauri/Cargo.toml` 的 `path` 依赖接入：
>
> ```toml
> tauri-plugin-screenshots = { path = "plugins/tauri-plugin-screenshots" }
> ```

## 本地基线

- 上游 tag：`v2.2.0`（上游该 tag 内 Cargo.toml 的 version 仍是 2.1.0，未同步；本地版本号写的是 2.2.0）
- 本地提交：`d9f6aa27`「补充了自定义修复后的截图插件」

## 为什么本地化了

上游依赖的 `xcap` 在 `is_valid_window()` 里会**按 PID 无条件过滤掉当前进程的窗口**。
这导致 Tauri 应用列不出、也截不到自己的窗口（上游 issue #8）。
本地新增了 Windows 专属实现绕开该限制。

## 与上游 v2.2.0 的真实差异

| 文件 | 差异 |
|---|---|
| `src/windows.rs` | **新增**。Win32 API 复刻 xcap 的窗口枚举与 GDI 截图链路，但去掉 PID 过滤，使自属窗口可枚举/可截图 |
| `src/commands.rs` | Windows 下 `get_screenshotable_windows` 走 `windows::enumerate_all_windows()`；`get_window_screenshot` 在 xcap 找不到窗口时回退 `windows::capture_own_window(id)`；顺带统一了错误处理写法 |
| `src/lib.rs` | 增加 `#[cfg(target_os = "windows")] pub mod windows;` |
| `Cargo.toml` | 版本号 2.1.0→2.2.0；`xcap` 0.3→0.9.6；新增 `log` + Windows 专属 `windows`/`image`/`widestring`/`scopeguard` 依赖 |

`windows.rs` 的具体实现点（复刻自 xcap）：

- 枚举：`EnumWindows` + 可见性/类名/扩展样式/DWM cloaked/空矩形过滤，无 PID 过滤
- 标题/应用名：`GetWindowTextW` / `GetFileVersionInfoW` + `VerQueryValueW`（优先 `FileDescription`）
- 截图链路：`PrintWindow(PW_RENDERFULLCONTENT=2) → PrintWindow(0) → PrintWindow(4) → BitBlt` 回退
- 后处理：BGRA→RGBA 交换 + 全透明像素置为不透明；按 DWM 帧边界裁剪（`#32770` 对话框特判不裁剪）；CatmullRom 缩放

## `permissions/` 的生成物（已 gitignore）

`permissions/autogenerated/`（command toml + reference.md）与 `permissions/schemas/schema.json`
是 `build.rs` 里 `tauri_plugin::Builder::new(COMMANDS).build()` 在**编译时生成**的产物，
已加入本插件 `.gitignore` 并从 git 取消跟踪（`default.toml` 是手写的，仍需跟踪）。
它们和上游唯一的内容差异是 CRLF/LF 行尾（`diff --strip-trailing-cr` 逐文件对比一致），
忽略后 `git status` 不再出现这条噪音。

## 升级/合并上游的注意事项

- 拉取上游新版本后，不要把 `src/` 直接覆盖，需保留上述三个文件的本地改动。
- 上游若升级了 `xcap` 版本，注意 `windows.rs` 里复刻的 Win32 调用与 `xcap` 内部实现可能不再一致，需回归验证自属窗口截图。
- 版本号要跟随上游 bump，别忘同步 `Cargo.toml` 的 `version` 与上游 tag。

## 复现对比命令

```bash
git clone --depth 1 --branch v2.2.0 \
  https://gh-proxy.org/github.com/ayangweb/tauri-plugin-screenshots /tmp/upstream
diff -r --brief /tmp/upstream/src src-tauri/plugins/tauri-plugin-screenshots/src
diff /tmp/upstream/Cargo.toml src-tauri/plugins/tauri-plugin-screenshots/Cargo.toml
```
