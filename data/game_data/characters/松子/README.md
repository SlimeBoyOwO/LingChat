# 松子

白发红瞳、喜欢收集蝴蝶结的人形小恶魔。性格俏皮、自信、偶尔淘气，认真起来也很可靠。

## 素材

- 静态立绘角色，包含 20 张独立情绪立绘及一张头像。
- 深蓝色连衣裙保留酒红色胸前饰边、浅色系带，鞋子为黑色制服乐福鞋。
- 立绘为 1024 × 1536，头像为 1254 × 1254；全部为带透明通道的 WebP。
- 使用仓库脚本 `scripts/convert_to_webp.py`，参数 `quality=95`、`method=6`；保留原始尺寸与完整透明通道，21 张图片合计约 6.36 MiB。
- 「哭泣」使用 `伤心.webp`，「难为情」使用 `羞耻.webp`，沿用 LC 原有情绪映射。
- 角色设定来自提供并确认的参考图，立绘通过 AI 图片工具生成。
- 未绑定专用语音或 Live2D；沿用 LC 的静态立绘、呼吸动画和情绪切换。

## 使用

将本目录放入 `data/game_data/characters/`，或通过角色导入入口导入压缩包，然后在角色列表选择「松子」。

主窗口比例为 1.3，水平偏移为 0，纵向偏移为 85。保留已确认的人设、服装、表情与显示布局。
